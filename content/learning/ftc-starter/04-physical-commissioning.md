# Commission an FTC Starter robot safely

Complete this activity with an experienced mentor. Simulation success is not permission to run a physical robot.

1. Put the robot on stable blocks, remove game pieces, and keep the Driver Station disabled.
2. Replace placeholder dimensions and tuning with measured, reviewed project data.
3. Match the Robot Controller configuration to the canonical descriptor names.
4. Use restrained hold-to-run diagnostics to confirm each motor's physical corner and inversion.
5. Check neutral mode, safe outputs, limits, wiring, addresses, and an accessible emergency stop.
6. Measure camera transforms and verify the official season tag map before accepting localization evidence.
7. Calibrate encoder scale and controls in small steps while recording measurements.
8. Regenerate, verify, run unit and simulator tests, and assemble the APK again.

Never copy calibration from another robot merely because that project builds. Record the hardware review and retain a known safe stop state for every mechanism.
